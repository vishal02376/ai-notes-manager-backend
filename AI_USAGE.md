## How AI Was Used During Development

### 1. Gemini API Integration
Anthropic Claude Opus was used to get guidance on integrating the Google Gemini API for the "Improve Note" AI feature.

The user writes note content and clicks "Improve with AI". The Gemini API rewrites the content to be clearer, more professional and grammatically correct, and the improved text is shown in the form before the user saves it.

### 2. Code Improvement
Claude Opus was used to review and improve some parts of the code, including:
- Code readability
- Error handling
- Refactoring suggestions
- Improving existing code structure

### 3. Folder Structure
Claude Opus was used to get suggestions for organizing the frontend and backend folder structure.
